Numbers & Percentages

Building the basics step by step.

TOPIC 01

Number System

The number system deals with different types of numbers and the properties used to solve numerical problems quickly.

Divisibility:
2 → last digit is even
3 → sum of digits is divisible by 3
5 → last digit is 0 or 5
9 → sum of digits is divisible by 9
10 → last digit is 0
Unit Digit: For powers, look at the repeating cycle of the last digit. Example: powers of 2 → 2, 4, 8, 6, then repeat.
LCM: Least Common Multiple — the smallest positive number divisible by all given numbers.
HCF: Highest Common Factor — the greatest number that divides all given numbers.
Remainder theorem: If a number N is divided by d, then N = dq + r, where 0 ≤ r < d.

💡 For fractions, compare values using a common denominator or cross multiplication when denominators are positive.

TOPIC 02

Percentage

Percentage means a value expressed out of 100. It is widely used in income, population, election, price and consumption problems.

Percentage = (Part / Whole) × 100
New Value after x% increase = Original × (100 + x) / 100
New Value after x% decrease = Original × (100 − x) / 100
Population model: New Population = P × (1 ± r/100), depending on increase or decrease.
Election model: Difference in votes = (Difference in percentage / 100) × Total valid votes.
Price–consumption: If price increases by x% and expenditure stays constant, new consumption = old consumption × 100/(100+x).

💡 Always identify the original quantity before calculating a percentage change.

DAY 02

Profit, Discount & Ratio

Turning formulas into problem-solving skills.

TOPIC 03

Profit & Loss

CP is Cost Price and SP is Selling Price. Profit occurs when SP > CP; loss occurs when CP > SP.

Profit = SP − CP
Loss = CP − SP
Profit % = (Profit / CP) × 100
Loss % = (Loss / CP) × 100
SP at p% profit = CP × (100 + p)/100
SP at l% loss = CP × (100 − l)/100
Successive changes: Net % = a + b + (ab/100), using + for increase/profit and − for decrease/loss.
Same SP: If one item has x% profit and another has x% loss, the overall result is a loss of x²/100%.

💡 Profit and loss percentages are normally calculated on CP, not SP.

TOPIC 04

Discount

MP means Marked Price. Discount is the reduction given on the marked price.

Discount = MP − SP
Discount % = (Discount / MP) × 100
SP = MP × (100 − Discount%)/100
Successive discounts:
Net Discount % = d₁ + d₂ − (d₁ × d₂)/100
Marked price & profit:
MP/CP = (100 + Profit%) / (100 − Discount%)

💡 Discount percentage is calculated on MP, while profit/loss percentage is normally calculated on CP.

TOPIC 05

Ratio & Proportion

A ratio compares two quantities of the same kind. A proportion states that two ratios are equal.

Ratio a:b = a/b
Equivalent ratios: a:b = ka:kb, where k ≠ 0.
Unknown ratio: If x:y = a:b, then x = ka and y = kb for some common multiplier k.
Proportion: a:b = c:d ⟹ a/b = c/d ⟹ ad = bc.

💡 Keep the order of quantities the same when forming a ratio.
