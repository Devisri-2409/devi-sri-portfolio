DAY 01 · TOPIC 01

Number System

The number system deals with different types of numbers and the properties used to solve numerical aptitude problems quickly.

Divisibility Rules

2 → last digit is even
3 → sum of digits is divisible by 3
5 → last digit is 0 or 5
9 → sum of digits is divisible by 9
10 → last digit is 0

Unit Digit

For powers, identify the repeating cycle of the last digit.

Powers of 2 → 2, 4, 8, 6 → cycle length = 4

For a large exponent, divide the exponent by the cycle length and use the remainder to identify the unit digit.

LCM & HCF

LCM = Least Common Multiple
HCF = Highest Common Factor

LCM is the smallest positive number divisible by all given numbers. HCF is the greatest number that divides all given numbers.

Remainder Theorem

N = dq + r
0 ≤ r < d

When N is divided by d, q is the quotient and r is the remainder.

Fractions

For positive denominators, cross multiplication can be used to compare fractions.

a/b > c/d if ad > bc

💡 Practice the basic divisibility rules first — they save time in many aptitude questions.
